# 지능형 전처리 및 고유명사 보호 (Smart Preprocessing)

Apple Silicon의 온디바이스 머신러닝 엔진(`NaturalLanguage` 프레임워크)을 활용하여 번역 품질을 정밀하게 보정하는 핵심 전처리 기능들입니다.

---

## 1. 스마트 언어 감지 및 건너뛰기 (Smart Skipping)
- 책의 모든 문단을 번역 엔진에 무조건 전달하지 않고, 문단 단위로 언어를 실시간 분석합니다.
- **건너뛰기 대상**:
  - 이미 목표 언어(예: 한국어)로 작성된 문단
  - 숫자, 기호, 코드 블록, 수식만으로 이루어진 문단
  - 번역이 불필요한 짧은 표식
- **효과**: 불필요한 연산 방지, 번역 속도 향상, 기존 원본 내용 왜곡 방지.

---

## 2. 문장 단위 정밀 분할 (`NLTokenizer`)
- 아주 긴 문단이나 복합 문장은 한 번에 번역할 경우 번역 모델의 버퍼 한계로 인해 문맥 누락이나 축약 현상이 발생할 수 있습니다.
- `NLTokenizer(unit: .sentence)`를 통해 자연어 문법 단위로 안전하게 쪼갠 후 번역을 수행하고, 번역 후 다시 문맥에 맞추어 하나의 문단으로 자연스럽게 재조합합니다.

---

## 3. 고유명사 및 용어집 보호 (Glossary Protection)
- 소설 속 인물 이름, 지명, 마법 주문, 기술 용어(예: `Baker`, `Hogwarts`, `SwiftUI`)가 엉뚱한 일반 단어로 번역되는 문제를 방지합니다.
- **작동 원리**:
  1. 원문 문장에서 지정된 용어를 특수 토큰(예: `__TERM_0__`)으로 임시 마스킹.
  2. 번역 세션 수행 (모델은 토큰을 건드리지 않고 문맥만 번역).
  3. 번역 결과물에서 사용자가 지정한 고정 번역어(또는 원문 그대로)로 안전하게 언마스킹 복원.
- **자동 추천 기능**:
  - EPUB 도서 분석 시 `NLTagger`가 인명(Person), 지명(Place), 조직(Organization) 등의 고유명사를 자동 감지하여 클릭 한 번으로 용어집에 등록할 수 있도록 추천합니다.
