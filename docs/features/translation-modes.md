# 3가지 번역 모드 (Translation Modes)

독자의 읽기 목적과 독서 스타일에 맞추어 세 가지 번역 모드를 제공합니다.

---

## 1. 이중 언어 모드 (Bilingual)

> **"원서 대조 독서와 어학 학습에 최적화된 모드"**

- **작동 원리**:
  - 원본 문단 바로 뒤에 번역된 문단을 연속으로 배치합니다.
  - 원문 문단에는 `.epub-original`, 번역문 문단에는 `.epub-translated` 클래스가 부여되어 시각적으로 명확하게 구분됩니다.
- **추천 대상**:
  - 원서의 원문 뉘앙스를 함께 확인하며 읽고 싶은 독자
  - 외국어(영어, 일본어 등) 원서를 통해 어학을 학습하는 독자

---

## 2. 번역문 대체 모드 (Replace)

> **"한국어(또는 목표 언어) 번역서처럼 자연스럽게 완독하는 모드"**

- **작동 원리**:
  - 원본 텍스트를 정밀 번역문으로 완전히 치환합니다.
  - 본문의 레이아웃, 인라인 스타일, 이미지 배치는 그대로 유지되면서 텍스트만 깔끔하게 교체됩니다.
- **추천 대상**:
  - 원서의 내용을 한국어 출판 서적처럼 빠르고 몰입감 있게 읽고 싶은 독자
  - 소설, 인문학 서적, 실용서 완독

---

## 3. 주석/토글형 모드 (Annotated)

> **"평소에는 번역문으로 읽고, 필요할 때 원문을 펼쳐보는 스마트 모드"**

- **작동 원리**:
  - HTML5 표준 태그인 `<details>`와 `<summary>`를 활용합니다.
  - 본문에는 번역문이 기본 표시되며, 문단 아래 `▶ 원문 보기` 토글 버튼을 클릭하면 원본 문단이 부드럽게 펼쳐집니다.
- **추천 대상**:
  - 본문은 쾌적하게 읽되, 번역이 애매하거나 원문의 표현이 궁금할 때 즉시 확인하고 싶은 독자
  - 기술 서적, 학술 서적, 복잡한 전문 용어가 포함된 도서
