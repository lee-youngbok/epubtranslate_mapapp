# 빠른 시작하기 (Quickstart)

단 몇 번의 클릭으로 원서 EPUB 도서를 번역하고 바로 읽을 수 있습니다.

---

## 단계별 사용 방법

### 1. EPUB 파일 불러오기
- 앱 창 중앙의 드롭 영역으로 `.epub` 파일을 드래그 앤 드롭하거나, 파일 선택 버튼을 눌러 가져옵니다.
- 파일이 로드되면 앱이 자동으로 책의 목차, 챕터 목록, 언어 분포(영어, 일본어 등)를 분석합니다.

### 2. 번역 옵션 설정
우측 설정 패널에서 원하는 옵션을 선택합니다:
1. **도착 언어 선택**: 번역될 목표 언어(예: 한국어)를 선택합니다.
2. **번역 모드 선택**:
   - `이중 언어`: 원문 아래 번역문 나란히 배치 (원서 대조용)
   - `번역문 대체`: 원문을 번역문으로 교체 (일반 번역서용)
   - `주석/토글형`: 번역문 우선 표시 + `▶ 원문 보기` 펼침 버튼
3. **글꼴(폰트) 설정**:
   - **번역문 폰트**: 한국어의 경우 `Pretendard (고딕)` 또는 `KoPubWorld 바탕 (명조)`을 추천합니다. 최초 선택 시 자동으로 다운로드되어 EPUB에 내장됩니다.
   - **원문 폰트**: 원서 출발 언어에 맞는 폰트(`Noto Sans` 등)를 선택하거나 `원본 폰트 유지`를 선택합니다.
4. **도서 정보 및 내보내기**:
   - 도서명과 저자명을 원하는 한글 이름으로 수정할 수 있습니다.
   - `완료 시 Apple 도서 앱으로 바로 보내기`를 켜두면 번역 완료 즉시 macOS 도서 앱에서 열립니다.

### 3. 번역 시작 및 내보내기
- 하단의 **[번역 시작]** 버튼을 누릅니다.
- Apple Neural Engine이 온디바이스로 번역을 수행하며 실시간 진행률이 대시보드에 표시됩니다.
- 번역이 완료되면 바로 Apple 도서 앱에서 책을 읽거나 원하는 위치에 번역된 `.epub` 파일을 저장할 수 있습니다.
