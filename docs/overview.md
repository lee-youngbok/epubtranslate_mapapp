# 제품 개요 (Overview)

## 기획 배경 및 비전

외국어 원서를 전자책(EPUB)으로 읽을 때, 기존의 기계 번역 서비스나 도구들은 다음과 같은 한계를 가지고 있었습니다:
1. **서식 및 레이아웃 파괴**: 번역 후 기존 책의 표지, 삽화, 챕터별 인라인 CSS 서식, 목차(TOC)가 망가지는 문제.
2. **개인정보 및 저작권 침해 우려**: 번역을 위해 도서 파일 전체를 외부 상용 클라우드 서버로 업로드해야 하는 위험.
3. **높은 API 토큰 비용**: 수십만 자에 달하는 원서 번역 시 발생하는 비용 부담.
4. **고정된 가독성**: 원문 언어와 번역문 언어의 폰트가 어울리지 않거나 깨지는 문제.

**EPUB Intelligence Translator**는 Apple Silicon의 Neural Engine(ANE)과 최신 Apple 온디바이스 프레임워크를 융합하여, **비용 0원 • 100% 오프라인 프라이버시 • 원본 구조 100% 보존 • 언어별 맞춤 폰트 임베딩**을 실현한 독자 맞춤형 번역 도구입니다.
